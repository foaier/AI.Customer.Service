# 业务分组、语义路由及实时调试入口

本增量按用户 2026-11-10 确认生效，覆盖旧文档中“用户中心拥有客服组及成员关联”的约束。客服上下文拥有业务组、成员关联、助手分类路由和申请路由快照；用户中心继续唯一拥有账号、租户及组织启用关系，不复制账号主表。

## 接待配置

每个租户、组织默认提供展商 EXHIBITOR、观众 VISITOR、媒体 MEDIA、其他 OTHER 四个业务组。成员保存用户中心账号引用，允许同一账号属于多个组。助手分别绑定四类咨询的接待组，支持四类指向同一个组。配置按组织版本 CAS 整体更新，成员写入前实时核验账号、租户及组织有效性；设置权限面向当前登录且在目标组织启用的账号，不依赖部署级静态白名单。设置页从用户中心已有组织分组读取成员候选，用户中心只读接口会重新核验分组归属，页面只接收账号ID和展示名。

业务组和路由持久保存。2026-11-11起正式组织营业日历也可持久设置，测试日历及企微探针仍仅用于联调；见[前端接口](frontend-api.md)。配置不删除组或历史路由事实；撤销成员关系后即时停止其接待权限。配置变更不会迁移已经创建的人工申请。

## 上下文分类

分类识别本次咨询主题，而非登录人的固定身份。通过项目统一模型工厂进行结构化语义判断，使用最近会话和当前尚未落库的真实用户输入。当前话题优先，否定身份与转话题必须处理；上下文不足、模型不可用、非法响应或低置信度均降为 OTHER，并保留降级原因。模型只能给出枚举类别，不能授予账号、组织、组或权限。

模型调用发生在核心事务外；直接申请、建议确认、调查 opt-in、系统故障四条入口都在创建申请的同一事务内固定类别、目标组、配置版本、分类策略、来源及 trace。重放保留首次快照。队列按业务组过滤；正文、回执、结束和跟进仍须核验当前认领者，禁止跨组窥探。

## WebSocket 同步

客服登录后直接使用现有登录令牌建立实时连接。浏览器在同源 WebSocket 首帧提交 `authorization,agent,conversationId,topOrgId,assistantConfigId,afterSeq`；Bearer 不进入 URL 或数据库。账号、租户从 JWT 解析，客服组织/助手/接待组按既有接单权限校验，访客归属从 Conversation owner 解析，客户端不能指定账号或租户。

订阅仅存连接内存。登录JWT到期时关闭连接；重连复用登录态并携带已处理游标。首次发送状态快照和afterSeq之后的持久消息，后续仅发送变化和心跳。

连接端定期读取持久事实以覆盖其他节点提交的变化；这是服务端增量扫描，不宣称数据库零轮询。每秒快照只核验本地业务组、会话归属与当前认领，首帧完成的用户中心账号/组织核验按每连接固定60秒复核，复核失败关闭连接；禁用生效窗口包含最多60秒加调度/请求耗时，本地撤销和改派仍在下一次扫描拒绝。JWT到期独立关闭，正常身份复核不强制重连。两个旧人工SSE接口及独立线程池已删除，只有WebSocket承载人工实时；AI文本生成保留原流式协议。前端保留接单、发送、回执等HTTP命令；手动接单只要求登录、业务组权限和容量，在线租约心跳只用于展示及接收同事改派。

## 页面与验收

统一入口提供助手选择，链接访客聊天、客服工作台、接待分组与助手路由、语义预览、营业日历与通知联调。设置页提供明确的保存、冲突、空成员和未绑定反馈。

验收覆盖双方言迁移、配置 CAS/隔离、成员撤权、四类路由及降级、所有申请来源的快照、跨组拒绝、真实 WebSocket 断线恢复与队列变化、无密集 HTTP 轮询、桌面和小屏页面。H2、模拟身份或模型替身只作为相应边界的开发验收，目标数据库、真实模型和 TLS/WSS 分别记录证据。
