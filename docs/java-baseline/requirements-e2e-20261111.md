## 发现与修复

1. **正式启动失败**：`@Resource taskMapper`按名称命中另一上下文TaskMapper，导致类型不匹配。明确客服systemHandoff Mapper Bean名称，新增真实Spring装配回归。
2. **配置查询失败**：共享库缺少五张路由配置表。维护窗口保存变更前结构快照，补齐路由表及值域触发器；ORM不会自动创建表，不把缺结构当空配置。
3. **营业时间无正式设置入口**：此前只有部署默认和测试实例覆盖。本轮补正式组织日历、ORM CAS、权限、预览和设置页；不重算历史等待期限。

5. **新增接口参数绑定失败**：正式构建未生成参数元数据，隐式`@RequestParam/@PathVariable`导致HTTP失败。新增入口显式命名并添加HTTP契约及注解回归。
6. **留言摘要读取409**：权限仓储要求共享事务，新表单读取未开启事务。补短事务及统一锁顺序，Spring真实事务拦截器回归通过，真实HTTP重验通过。
7. **运营导出缺失**：补Conversation owner分页投影和前端JSON下载，核验组织/助手归属，过滤系统和内部请求信息。
